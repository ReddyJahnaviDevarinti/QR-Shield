# Frontend Features Directory

This directory organizes domain-specific feature modules for QRShield AI:

- `verification/`: Ingestion, viewfinder, and verification result presentation (Planned - Phase 4/5)
- `merchants/`: Merchant profile management and reference QR uploads (Planned - Phase 3)
- `sample-lab/`: Interactive demonstration and benchmark inspection (Planned - Phase 9)
- `history/`: Audit log table and inspection modal (Planned - Phase 10)

Feature implementations will be constructed sequentially according to the project development phases.
